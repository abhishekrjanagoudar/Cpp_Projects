A structured collection of C++ practice tasks for the **Advanced Programming Techniques** course — covering labs and past exam question banks, all organised by domain.

Each task folder contains:
- 🧩 A complete or starter C++ codebase in `myCode/`
- 🧪 A `tests.cpp` describing required behaviour (exam tasks)
- 📄 A PDF exam/lab specification
- 📝 An individual `README.md` explaining classes and concepts
